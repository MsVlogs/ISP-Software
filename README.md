# ISP-Software

ISP management platform with OLT/ONU monitoring and network operations tooling.

## Network Monitoring

The application now includes a unified Network Monitoring module with:

- Network Map
- Traffic Monitor
- High Usage Monitor
- Device Watcher
- Logs & Alerts

The module reuses collected `onu_status` metrics and the existing OLT inventory. Geographic map coordinates can be added to network nodes when physical locations are available.
